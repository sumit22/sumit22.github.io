Open source

Things I've built in public, each solving a problem I hit in production.

sendrail

Email deliverability on your own AWS SES account: sending, delivery feedback, suppression and reputation. It's the layer you'd otherwise rent from an email service provider, so the domain reputation stays yours.

TypeScript, AWS SES, Express and NestJS adapters
View repository

FindMyStar

An offline mobile app that points you at any of ~620 stars, planets and deep-sky objects with an AR arrow. Positions are computed in Rust against VSOP87 and Hipparcos data and validated against USNO and JPL Horizons. It makes no network calls.

Rust core over FFI, React Native, SQLite
View repository

time-travel-carousel

A React carousel where every slide has a version history: left and right move between items, up and down move through their revisions. It loads files through your own authenticated client and has zero runtime dependencies.

TypeScript, React
View repository
